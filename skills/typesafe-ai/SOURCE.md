## Install for Claude Code (preferred — gets updates)

```bash
claude plugin marketplace add typesafe-ai/skills
claude plugin install typesafe@typesafe-ai
```

Or copy this folder into `~/.claude/skills/typesafe-ai/`.
Using the API needs a key from https://console.typesafe.ai/keys, exported as `TYPESAFE_API_KEY`.
